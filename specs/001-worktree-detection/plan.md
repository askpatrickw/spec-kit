# Implementation Plan: Git Worktree-Aware Workflows

**Branch**: `001-worktree-detection` | **Date**: 2026-01-31 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/001-worktree-detection/spec.md`

## Summary

This feature extends Spec-Kit's Git detection capabilities to support worktree-based workflows alongside existing branch-based and no-Git modes. The system will auto-detect the Git environment during initialization, create a JSON configuration file to persist the chosen mode, and adapt all Git operations (detection, validation, feature creation) based on the configured mode. The implementation prioritizes backward compatibility (zero breaking changes to existing projects) and simplicity (blocking mode switching to avoid migration complexity).

**Constraints**: Must maintain 100% backward compatibility with existing projects; must work with Git 2.13+ (first version with robust worktree support)  
**Scale/Scope**: Single-user CLI tool, expected to manage 10-100 worktrees per project

### Data Model (data-model.md)

**Entities**:

1. **ConfigFile**
   - **Location**: `.specify/memory/config.json`
   - **Fields**:
     - `source_management_flow`: enum (branch | worktree | none)
     - `worktree_folder`: string (path, optional - only when flow=worktree)
     - `version`: string (config schema version, e.g., "1.0")
   - **Validation Rules**:
     - `source_management_flow` must be one of three valid values
     - `worktree_folder` must be present when flow=worktree
     - `worktree_folder` must be absent or null when flow=branch or none
   - **State Transitions**: Immutable after creation (FR-017)
   - **Defaults**:
     - `source_management_flow`: Auto-detected based on Git environment
     - `worktree_folder`: `./worktrees` (when flow=worktree)

2. **GitEnvironment** (transient, not persisted)
   - **Attributes**:
     - `is_repo`: boolean (result of git repository detection)
     - `is_worktree`: boolean (result of worktree detection)
     - `is_bare`: boolean (result of bare repo detection)
     - `has_git`: boolean (result of git existence check)
     - `suggested_mode`: string (derived mode suggestion: "branch" | "worktree" | "none")
   - **Derivation Logic**:
     ```
     if not has_git: 
       → suggested_mode = "none"
     elif is_worktree: 
       → suggested_mode = "worktree"
     elif is_bare: 
       → suggested_mode = "worktree"
     else: 
       → suggested_mode = "branch"
     ```

3. **WorktreeMetadata** (transient)
   - **Attributes**:
     - `path`: Path (absolute path to worktree directory)
     - `branch_name`: string (associated branch, format: ###-feature-name)
     - `registered`: boolean (whether Git knows about this worktree)
   - **Validation**:
     - Directory name must match branch name (FR-010)
     - Path must be under configured worktree_folder (FR-008)

**Contract 2: Detection Functions Interface** (`contracts/detection-api.md`)

```markdown
## Git Detection API

### is_git_worktree() -> bool
Detects if current directory is a registered Git worktree.

**Returns**: True if worktree, False otherwise
**Implementation**: `git worktree list | grep "$(pwd)"`
**Performance**: <100ms

### is_bare_repo() -> bool
Detects if repository is bare.

**Returns**: True if bare, False otherwise
**Implementation**: `git rev-parse --is-bare-repository`
**Performance**: <50ms

### detect_git_environment() -> GitEnvironment
Combines all detections into environment classification.

**Returns**: GitEnvironment object
**Performance**: <200ms (runs all checks)
```

**Contract 3: Config API** (`contracts/config-api.md`)

```markdown
## Configuration Management API

### load_config(path: Path = None) -> dict | None
Loads and validates config file.

**Parameters**:

**Returns**: Parsed config dict or None if not found
**Raises**: ValueError if config is invalid
**Performance**: <50ms

### save_config(config: dict, path: Path = None) -> None
Writes config to disk with validation.

**Parameters**:
- config: Config dictionary matching schema
- path: Optional path override

**Raises**: ValueError if config doesn't match schema
**Performance**: <50ms
```
